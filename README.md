# Drawbridge
맥북과 Lenovo Android 펜 태블릿을 연결하는 네이티브 실시간 화이트보드입니다. macOS 앱과 Android 앱이 WebSocket 서버를 통해 필기와 필압을 공유하며, 양쪽 앱에서 필기를 벡터 PDF로 저장할 수 있습니다.

## 현재 맥에서 USB 연동 테스트
```sh
npm start
```
서버가 실행된 상태에서 [Drawbridge.app](./dist/Drawbridge.app)을 열고 **새 보드**를 눌러 6자리 코드를 만듭니다.

1. Lenovo 태블릿에서 개발자 옵션과 USB 디버깅을 켜고 맥에 USB로 연결합니다.
2. `./scripts/install-android.sh`를 실행합니다. APK 설치와 `adb reverse` 포트 연결을 함께 설정합니다.
3. Android 앱의 서버 주소 `http://127.0.0.1:3000`을 유지하고 맥 앱의 6자리 코드를 입력해 **연결**을 누릅니다.
4. 태블릿 펜으로 그린 뒤 맥 앱에 같은 선이 나타나는지 확인합니다.
5. 양쪽의 **PDF 저장**으로 벡터 필기 PDF를 저장합니다.

맥 앱에서 **QR · 링크**를 누르면 현재 LAN 주소와 방 코드가 포함된 QR이 표시됩니다. Android 기본 카메라로 QR을 스캔하면 Drawbridge 앱이 열리고 서버 주소와 코드가 자동으로 채워져 연결됩니다. **링크 복사**로 `drawbridge://` 초대 링크를 메신저 등에 전달할 수도 있습니다.

## Mac 설치

저장소를 받은 뒤 한 번만 실행합니다.

```sh
./scripts/install-macos.sh
```

스크립트는 Homebrew로 Node.js와 `cloudflared`를 확인하고, 의존성을 설치한 뒤 Drawbridge를 `~/Applications`에 설치해 실행합니다. Homebrew가 없는 경우 먼저 [Homebrew](https://brew.sh)를 설치해야 합니다.

Mac 앱의 **연결 설정**에서 연결 방식을 한 번에 선택합니다. **외부 세션 시작**은 서로 다른 네트워크용 Cloudflare 터널을 자동으로 열고, **같은 Wi-Fi 시작**은 인터넷 터널 없이 내장 서버만 실행합니다. 주소가 준비되면 참여 코드가 자동 생성되므로 **초대 QR**을 눌러 Android 카메라로 스캔하면 됩니다. 이미 생성된 세션에 참여할 때만 서버 주소와 참여 코드를 입력합니다.

외부 세션에서 Mac 앱 자체는 항상 로컬 내장 서버에 연결하고, 검증이 끝난 공인 주소만 초대 QR에 사용합니다. Cloudflare 임시 호스트의 DNS 전파가 늦더라도 세션 생성이 실패하지 않으며, 상단 상태가 **외부 세션 준비됨**으로 바뀐 뒤 QR을 열 수 있습니다.

Mac 화면은 연결 기능과 필기 기능을 두 줄로 분리했습니다. 위쪽에는 연결 설정·초대·화면 공유와 현재 상태만 표시하고, 아래쪽에는 되돌리기·필기 도구·색상·굵기·확대만 둡니다. 이미지, 화면 위 필기, PNG/JPG, PDF 기능은 **더보기** 메뉴에 있습니다. Android도 서버 주소와 코드를 **연결 설정** 모달로 옮기고 필기 도구·색상·굵기·파일 작업을 짧은 선택 메뉴로 묶었습니다.

## 필기와 콘텐츠

- **펜 / 지우개**: 지우개가 닿은 필기 선 전체가 양쪽 기기에서 제거됩니다.
- **되돌리기**: 현재 기기에서 만든 마지막 필기 선을 제거하고 연결된 모든 기기에 즉시 반영합니다.
- **펜 설정**: 펜, 사각 마커, 반투명 형광펜 유형과 색상, 1–16 굵기를 선택할 수 있습니다.
- **확대/축소**: 보드를 50–400%로 확대할 수 있으며 확대 상태의 펜 좌표는 원래 화면 좌표로 변환되어 상대 기기에 정확히 표시됩니다.
- **핀치 확대**: Android에서는 두 손가락 핀치, Mac에서는 트랙패드 확대 제스처로 50–400% 범위에서 연속 확대할 수 있습니다. 두 손가락 제스처 중에는 필기 입력을 중단해 확대 동작이 선으로 기록되지 않습니다.
- **화면 회전**: Android 휴대폰과 태블릿에서 가로·세로 방향을 자유롭게 전환할 수 있고 회전해도 방 연결을 유지합니다. 좁은 세로 화면에서는 연결 도구와 펜 도구를 각각 가로로 스크롤할 수 있습니다.
- **전체 지우기**: 연결된 모든 기기의 필기만 지우며 배경 이미지는 유지합니다.
- **이미지**: PNG, JPEG, HEIC 이미지를 보드 배경으로 넣고 연결된 기기에 공유합니다.
- **내보내기**: 배경 이미지와 필기를 PNG/JPEG 또는 벡터 PDF로 저장합니다.
- **화면 위 필기**: macOS에서는 투명한 최상위 캔버스로 전환해 브라우저, Notion, Confluence 등 다른 앱 위에 필기합니다. 이미지 내보내기를 누르면 ScreenCaptureKit으로 아래 화면과 필기를 합성합니다. 최초 사용 시 macOS 화면 기록 권한을 허용해야 합니다.
- Android의 화면 위 필기는 투명 주석 레이어를 제공합니다. Android 보안 정책상 다른 앱 화면까지 파일로 합치는 기능은 MediaProjection 사용자 승인이 필요하며, 현재 버전의 PNG/PDF 내보내기는 보드 또는 가져온 이미지와 필기를 저장합니다.

## Mac 화면을 태블릿에서 보며 필기

1. 맥과 Android 기기를 같은 방에 연결합니다.
2. 맥 앱에서 **Mac 화면 공유**를 누르고 최초 한 번 macOS 화면 기록 권한을 허용합니다.
3. Android 보드에 맥 화면이 실시간으로 표시됩니다. 현재 문서와 필기 용도에 맞춰 약 2fps, 최대 가로 1280px로 전송합니다.
4. Android 펜으로 쓰면 동일한 정규화 좌표의 필기가 맥 앱에도 표시됩니다.
5. Android에서 PNG/PDF로 저장하면 마지막으로 수신한 맥 화면과 필기를 합성합니다.

화면 공유 중에는 macOS 전체 화면 위에 클릭을 방해하지 않는 투명 주석 창이 자동으로 표시됩니다. 모바일에서 쓴 선은 Drawbridge 보드와 현재 맥 화면 양쪽에 나타납니다. 투명 주석 창은 화면 캡처 프레임에서 제외되므로 Android에서는 화면 영상과 벡터 필기가 겹쳐 보이지 않습니다.

Drawbridge 자체의 모든 창은 ScreenCaptureKit의 애플리케이션 단위 필터로 공유 화면에서 제외합니다. 따라서 맥의 주석 레이어가 화면 영상에 들어간 뒤 Android 벡터 필기와 다시 겹치는 이중 표시를 방지합니다.

## 단축키

| 기능 | macOS | Android 하드웨어 키보드 |
| --- | --- | --- |
| 되돌리기 | `⌘Z` | `Ctrl+Z` |
| 펜 | `⌘⇧P` | `Ctrl+P` |
| 지우개 | `⌘⇧E` | `Ctrl+E` |
| 확대 / 축소 | `⌘+` / `⌘-` | `Ctrl++` / `Ctrl+-` |
| 100% | `⌘0` | `Ctrl+0` |

화면 자체는 JPEG 프레임, 필기는 좌표 벡터로 따로 전송되므로 필기 선은 화면 프레임보다 즉각적으로 동기화됩니다. 영상 재생이나 원격 마우스 조작 용도가 아니라 문서 검토와 주석을 위한 모드입니다.

## Firebase App Distribution
Firebase 프로젝트 `gesture-app-18fec`에 패키지 `com.drawbridge.app`의 Drawbridge 앱이 등록되어 있습니다. 새 APK를 빌드한 뒤 다음 명령으로 지정한 테스터에게 배포합니다.

```sh
./scripts/distribute-android.sh tester@example.com
```

이 명령은 APK를 Firebase에 업로드하고 해당 주소로 설치 초대를 보냅니다.

빌드 산출물:

- macOS: `dist/Drawbridge.app`
- Android: `android/app/build/outputs/apk/debug/app-debug.apk`

다시 빌드하려면 `./scripts/build-macos.sh`와 `cd android && ./gradlew assembleDebug`를 실행합니다.

## 외부 접속용 배포
공용 서버와 도메인이 필요합니다. 서버에 Docker Compose를 설치하고 도메인의 DNS를 서버 IP로 설정한 뒤:
```sh
DOMAIN=board.example.com docker compose up -d --build
```
실제 도메인으로 바꾸세요. 서버의 80/443 포트가 열려 있어야 하며 Caddy가 HTTPS 인증서를 발급합니다. 회사에서 허용하는 서버/도메인을 사용하세요. 서버를 여러 인스턴스로 늘리면 방 상태가 공유되지 않으므로 현재는 단일 앱 인스턴스로 실행합니다.

Mac 0.5.0부터 중계 서버와 역방향 터널 실행이 앱에 통합되어 있습니다. **연결 설정 → 외부 세션 시작**을 누르면 임시 `trycloudflare.com` 주소가 생성되어 QR에 포함됩니다. Quick Tunnel은 개발·개인 작업용 임시 기능이며 주소는 실행할 때마다 바뀝니다. 고정 주소와 운영 보장이 필요하면 별도의 Cloudflare named tunnel 또는 공용 서버 배포를 사용합니다.

1. 맥북에서 배포한 `https://board.example.com` 주소를 엽니다.
2. **기기 연결 → 초대 링크 복사**로 링크를 태블릿 브라우저에서 엽니다. 또는 같은 주소에서 맥북의 연결 코드를 입력합니다.
3. 태블릿에서 그리면 맥북에도 실시간 반영됩니다. **펜 입력만**을 켜면 손가락 입력을 무시합니다.
4. 맥북에서 **화면 공유**를 누르고 화면/창을 선택합니다. macOS 화면 기록 권한이 필요할 수 있습니다. 태블릿에서 수신 화면 위에 필기하면 양쪽에 표시됩니다.
5. 회의 앱에 송출하려면 맥북의 Drawbridge 창을 그 회의 앱에서 공유합니다. 화면 전체를 다시 공유하면 무한 거울 현상이 생길 수 있어 원본 창을 선택하는 편이 좋습니다.

## 전송 방식 및 현재 범위
- 필기: HTTPS POST + SSE, 필압/색/굵기/지우개/내 필기 되돌리기/전체 삭제.
- 화면: HTTPS 서버를 통한 JPEG 프레임 중계, 최대 약 3fps·1280×720. 문서와 필기용이며 동영상용 고프레임 스트리밍이나 오디오는 지원하지 않습니다. NAT, 서로 다른 Wi-Fi, UDP 차단 환경에서 직접 기기 연결이나 TURN 없이 동작하도록 설계했습니다. 회사망이 배포 도메인 또는 장시간 HTTP 응답을 차단하면 네트워크 관리자 허용이 필요합니다.
- PNG 저장에는 공유 화면과 필기가 함께 포함됩니다.
- 방 코드는 접근 키이며 코드를 아는 사람은 보고 수정할 수 있습니다. 현재는 프로토타입으로 SSO, 접근 감사, 접속 시도 제한은 없습니다. 사내 기밀을 다루는 운영 배포 전에는 회사 인증/접근 통제를 추가해야 합니다.
- HTTPS는 전송 구간을 암호화하지만 서버는 필기와 화면 프레임을 처리합니다. 종단간 암호화는 아닙니다.
- 보드는 메모리에 저장됩니다. 서버 재시작 시 사라지며 빈 방은 24시간 후 삭제됩니다. 영구 저장은 PNG를 사용합니다.
- 방당 최대 8개 참여 세션, 5000 스트로크, 스트로크당 4096 포인트. 새로고침은 새 참여 세션으로 계산합니다.
- 맥북 Chrome/Edge + Android Chrome을 우선 대상으로 구현했습니다. 시스템 전체 주석, 태블릿의 맥 원격 제어는 제공하지 않습니다.
- Google Fonts를 불러오지 못하면 시스템 글꼴을 사용합니다.

## 로컬 개발
Node.js 20 이상, 추가 패키지 설치 없이:
```sh
npm start
```
맥북에서 http://localhost:3000 을 엽니다. 이것만 실행해서는 다른 네트워크의 태블릿이 접속할 수 없으며, 위의 공용 HTTPS 배포가 필요합니다. 같은 Wi-Fi에서만 개발 중 시험하려면 연결 창에 표시되는 LAN 주소를 사용할 수 있습니다.

## 검증
```sh
npm test
node --check public/app.js
```
서버 방 생성, 참여, 권한 검사, 필기 검증, SSE 동기화와 되돌리기를 테스트합니다. 실제 회사망/핫스팟 간 화면 수신과 펜 필압은 실기기에서 확인해야 합니다.
